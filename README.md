# ai-prompts

Личная коллекция промптов для работы с AI-агентами (Claude Code, ChatGPT,
Cursor и т.п.).

## Идея

Промпты здесь написаны так, чтобы их можно было **просто скормить агенту** —
дальше он сам разберётся: оценит контекст, задаст уточняющие вопросы, при
необходимости разобьёт работу на шаги. Никаких жёстких параметров, плейсхолдеров
вида `{{input}}` и пошаговых сценариев — задача агента в том, чтобы быть умным,
а задача промпта — задать ему направление и рамки.

## Как пользоваться

1. Найди подходящий промпт в одной из категорий ниже.
2. Скопируй содержимое `.md` файла и отправь агенту первым сообщением.
3. Дальше работай в диалоге — агент сам спросит то, что ему нужно.

## Структура

```
prompts/
├── coding/         — код-ревью, рефакторинг, тесты, отладка
├── writing/        — тексты, документация, сообщения коммитов
├── analysis/       — анализ кода, архитектуры, ресёрч
├── productivity/   — планирование, чек-листы, разбор задач
├── meta/           — промпты для генерации и улучшения других промптов
├── modules/        — надстройки над базовыми промптами (подключаются
│                    проектом опционально, по applicable_to)
└── index.yml       — сгенерированный индекс всех промптов (key, path,
                     raw, SHA-256). Используется проектами-потребителями
                     для быстрой синхронизации через паттерн source-sync.
                     Собирается командой `npm run index:build`.

patterns/           — переиспользуемые блоки правил, инлайнящиеся в тело
                     промптов (source-sync и т.п.).

skills/             — skills (SKILL.md по стандарту Agent Skills), которые
                     контракты и модули ставят в проекты; в индексе.

agents/             — субагенты (канон), которые ставятся в проекты;
                     в индексе.

presets/            — пресеты: готовые наборы модулей с ответами на их
                     вопросы под тип проекта; в индексе.

design/             — спецификации будущих версий промптов (не промпты,
                     в индекс не попадают).

harness/            — пакет @shahimat/harness (TS, npm workspaces, Node ≥ 24):
                     сборка index.yml этого репо; проверки и генерация
                     для проектов на контракте v3.
```

Подробнее — `patterns/README.md`, `prompts/modules/README.md`,
`CONTRIBUTING.md`.
