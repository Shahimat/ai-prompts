# Журнал @shahimat/ai-core

Свежее сверху. Одна версия — список новых команд и проверок.

## 0.1.1

- Дельта, попавшая в коммит после сбоя сессии, закрывается: пункт
  засчитывается, если цель изменена в коммитах с появления дельты;
  `delta check` предупреждает о закоммиченной дельте.
- `delta check --name` и `delta close --name`: нарушения в чужих дельтах
  — предупреждение со списком файлов, а не провал.
- Дельта не прошла схему — ошибка схемы идёт первой, производные
  нарушения «без revise» по её целям свёрнуты в одну строку.
- peer `vitest` — `>=3`: проекты на vitest 3 ставятся без ERESOLVE.

## 0.1.0

- `delta close --name <дельта>` закрывает только эту дельту: чужая
  невыполненная больше не валит close. Принятые `revise` до коммита
  помнит `context/.delta/.accepted.json` — следующая сессия не падает
  «знание без revise». `target` с якорем `файл#поле` сверяется по файлу,
  пункт о файле внутри `context/.delta/` считается выполненным.

- Прогон роли прозрачен: журнал stream-json пишется в файл по мере
  работы, `onProgress` получает строки «роль X: шаг N — инструмент»,
  таймаут роли (по умолчанию 30 мин, `HARNESS_ROLE_TIMEOUT_MIN`)
  останавливает `claude -p` с понятной причиной вместо тихого ожидания.

- Роли: `askRole(root, name, task, { transcript, addDirs })` — полный
  stream-json прогона в файл журнала и доступ роли к каталогам вне
  проекта (`--add-dir`, копия репозитория job).
- Hook `ops-brief`: `adapters sync` при `hooks: [ops-brief]` ставит
  `ai ops brief` в `SessionStart` (`startup`, `resume`, `compact`).
- `CommandArgs`: `all`, `every`, `until`, `job`, `timeout` — опции
  рантайма `ops`.

- Пакет выделен из `@shahimat/harness`: команды (`index`, `adapters`,
  `changelog`, `context`, `delta`, `expect`, `secrets`, `outdated`,
  `role`), скрипты (`check`, `refresh`), механизм ожиданий
  (`@shahimat/ai-core/expect`) и роли (протокол, MCP-канал, запуск
  `claude -p`). CLI — `ai-core`; автоматы остались в
  `@shahimat/harness`.
- Конфиг проекта — `context/ai-core.yml` (было `context/harness.yml`);
  ключа `version` нет — версии пакетов в `package.json` проекта,
  `outdated` сверяет оттуда `@shahimat/ai-core` и `@shahimat/harness`.
- `docs guard` — hook `PreToolUse`: правка документации и генерируемых
  файлов в основной сессии — отказ с кодом 2; `adapters sync` ставит
  его в `.claude/settings.json` при `hooks: [docs-guard]`.
- Метка генерируемых файлов и заголовки индексов — «generated by
  ai-core …».
