# Журнал @shahimat/ai-core

Свежее сверху. Одна версия — список новых команд и проверок.

## 0.1.0

- Роли: `askRole(root, name, task, { transcript, addDirs })` — полный
  stream-json прогона в файл журнала и доступ роли к каталогам вне
  проекта (`--add-dir`, копия репозитория job).
- Hook `ops-brief`: `adapters sync` при `hooks: [ops-brief]` ставит
  `ai ops brief` в `SessionStart` (`startup`, `resume`, `compact`).
- `CommandArgs`: `all`, `every`, `until`, `job`, `timeout` — опции
  рантайма `ops`.

- Пакет выделен из `@shahimat/harness`: команды (`index`, `adapters`,
  `changelog`, `context`, `delta`, `expect`, `secrets`, `outdated`,
  `role`), скрипты (`check`, `refresh`), механизм ожиданий
  (`@shahimat/ai-core/expect`) и роли (протокол, MCP-канал, запуск
  `claude -p`). CLI — `ai-core`; автоматы остались в
  `@shahimat/harness`.
- Конфиг проекта — `context/ai-core.yml` (было `context/harness.yml`);
  ключа `version` нет — версии пакетов в `package.json` проекта,
  `outdated` сверяет оттуда `@shahimat/ai-core` и `@shahimat/harness`.
- `docs guard` — hook `PreToolUse`: правка документации и генерируемых
  файлов в основной сессии — отказ с кодом 2; `adapters sync` ставит
  его в `.claude/settings.json` при `hooks: [docs-guard]`.
- Метка генерируемых файлов и заголовки индексов — «generated by
  ai-core …».
