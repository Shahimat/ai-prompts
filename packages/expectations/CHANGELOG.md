# Журнал @shahimat/expectations

Свежее сверху.

## 0.2.0

- Наборы объявляют разделы через `describe` из `@shahimat/harness/expect`:
  ожидания приписываются файлу, который применил набор, — при одной точке
  входа отчёт и проверка заголовков идут по этому файлу.
- `attention(...keys)` — принцип «внимание пользователя — самый дорогой
  ресурс»: вопрос только по необходимости, основная сессия — на доменной
  области.
- `ticketCommits(...keys)` — доказательства по якорям `expect:KEY`, а не
  по путям.
- Уточнено: «по умолчанию коммит делает пользователь» — не противоречит
  git-записи агента по явной просьбе.
- `ticketCommits`: ожидание «в плане соседние шаги одного типа
  объединены; scope и тема шаг не делят».

## 0.1.0

- `ticketCommits(evidence)` — правила «тикеты и коммиты».
