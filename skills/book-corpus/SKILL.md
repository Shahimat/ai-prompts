# book-corpus

Книга превращается в сущности слоя `analysis` (skill `analysis`) за
несколько проходов. Целиком в контексте её не держим.

## Хранилище и канал

- Сырой текст — во внешнем корпусе; в git не коммитится и в примеры не
  копируется.
- Доступ — канал `corpus` в `context/data-access.yml`, правила — skill
  `data-access`. Секретов в репозитории нет.
- В git — только производное: `source` книги, `map`, `claims` с
  локаторами. Цитата в `quote` — короткий фрагмент ради сверки, не
  пересказ главы.

## Проходы

**Проход 0 — приём.** Книга — `analysis/sources/<id>.yml`:
`type: book`, провенанс `primary` (текст автора) или `secondary`
(комментарий, учебник), `locator_base` — handle в корпусе + издание.
Транспорт ≠ провенанс: книга из корпуса не `app-telemetry`.

**Проход 1 — карта (дёшево).** Оглавление по каналу → поле `map`: по
строке-резюме на главу. Навигация «куда смотреть» без чтения тела.

**Проход 2 — тезисы (средне).** По карте — ключевые `claims` с точным
`locator` (глава / раздел / страница издания) и дословным `quote`,
сверенным по каналу. Локатор — гарантия атрибуции: к месту всегда можно
вернуться.

**Проход 3 — глубокое чтение (дорого, по требованию).** Полный текст
главы — только когда `inquiry` навёл на неё. Режем по естественной
структуре (главы, разделы), не по токен-окнам. Новые тезисы — как в
проходе 2; затронутые позиции — `reconciled: false` (skill `analysis`).

Проходы 0–1 делаются при регистрации; 2 — по плану с пользователем
(какие главы), 3 — только по запросу.

## Поле `map`

Добавляется в `analysis/sources/<id>.yml` только при `type: book`.

```yaml
id: treatise-sovereign
kind: source
namespace: philosophy
summary: <автор A>, трактат о суверене и общественном договоре
type: book
provenance: primary
origin: <автор A>, <название>, <издание>
locator_base: corpus://treatise-sovereign · <издание>
map:
  - ch1: О природе человека — страсти, равенство, война всех
  - ch2: О договоре — передача права суверену
verified: false
verified_at: null
verified_note: атрибуция цитат сверяется по главам при обращении
claims: [treatise-state-of-nature]
```

- ключ — стабильный короткий идентификатор главы (`ch<N>`, `part<N>`),
  он же начало `locator` тезисов;
- значение — одна строка: тема главы, без цитат;
- уровень — главы (части); глубже не детализируем: глубина достаётся
  проходом 3. Больше ~40 строк — книгу дробим на источники по частям
  (`<id>-part<N>`), по одному `source` на часть.

## Недоступный канал

- Корпус недоступен — сверить цитату нельзя: тезис остаётся
  `verified: false`, `verified_note: атрибуция не сверена: канал corpus
  недоступен`.
- Цитату по памяти не восстанавливаем и не «уточняем»; нужен ответ
  сейчас — пересказ с пометкой «пересказ, не сверено».
- Карту по памяти не строим: проход 1 откладывается, в отчёте — блокер
  «канал corpus».

## Проверки

- в git нет сырого текста книг (файлы глав, выгрузки, длинные `quote`);
- у `source` с `type: book` есть `locator_base` с handle и `map`;
- `locator` тезиса книги начинается с ключа из `map`;
- `verified: true` у тезиса книги — только после сверки по каналу.
