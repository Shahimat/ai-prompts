# source-sync

Применение паттерна `source-sync` (`patterns/source-sync.md` в источнике
`ai-prompts`). Его inline-копия живёт в reference соответствующей версии.

Выбери **один** протокол:

- действующий или явно выбранный самостоятельный v2 —
  [references/v2.md](references/v2.md);
- v3, включая явно запрошенный переход v2 → v3 —
  [references/v3.md](references/v3.md).

Для обновления версию определяют `AGENTS.md` и `sync.contract.key`,
для перехода — явный запрос. При неоднозначности уточни цель до правок;
наличие старого каталога или `deprecated` в индексе не разрешает сменить
контракт. Установка и миграция **на v2** — skill `contract-setup`.

Не загружай оба reference целиком. Внутренние ссылки относительны к файлу
reference. Ветка v2 не запускает установщик, CLI или роли v3;
`metadata.runs: source-sync` относится только к ветке v3.

Подключение и отключение модулей v2 — дополнительно
[references/modules-v2.md](references/modules-v2.md), только для такой задачи.
Поставка файлов skills не означает загрузку их инструкций в контекст.
