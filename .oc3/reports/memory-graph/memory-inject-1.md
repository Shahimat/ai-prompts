# memory-inject — отчёт 1

## done

- oc3-хук первого промпта сессии: `appendBriefing` (session-brief.ts) после строки брифинга вызывает `memoryStart(root)` — build-if-stale (checkBundles; стухше или бандлов нет → buildBundles + writeGraph на месте; холодный старт без бандлов строится) и вшивает стартовый index во вход сессии отдельным system-part «Оперативная память проекта (стартовый граф)». Один экземпляр на сессию — существующий `seen`-set. Хост-механика, модель не участвует.
- Крит после сборки (например переполнение старта) — вшивания нет, диагностики уходят в host-лог (`oc3 memory: <file>: <message>`) — громкий отказ без мусора в контексте.
- Вшивание в роли — через harness-раннер: `runRole` (packages/ai-core/src/lib/role.ts) добавляет к system prompt стартовый index (`memoryPromptOf`) и узлы из маркеров брифа «память: <sha12>»; повторный маркер/дубликат — узел вшивается ровно один раз (Set); неизвестный узел — `UsageError` с перечнем валидных (или «бандлы не собраны, запусти ai memory build»). Плагин в child-сессиях не грузится — механика в коде раннера.
- Тесты через fake-opencode: fake дополнительно читает instructions.md и записывает `system` в args.jsonl; тесты: маркер → узел в system; без маркеров → старт ровно один раз; неизвестный узел → отказ с перечнем; dedupe маркеров. session-brief.test.ts: свежие бандлы → вшивание один раз на сессию; холодный старт и стухшие → build на месте, prune; крит → без вшивания; нет манифеста → без памяти и без аварий.
- Cold-start крит: уже реализован предыдущими тикетами — install.ts: plugins-детект (plugin vs plugins), пин версии, runtime: full дефолт / degraded при недоступном реестре (npm ping), upsertRuntimeYaml. Дополнительных правок не требовал.
- «в бандлах по одному рендеру на каждый namespace файла; в сессию вшивается ровно один экземпляр» — обеспечено группировкой манифеста (узел на пару) и Set-дедупликацией маркеров + один system-part старта.
- Живая проба вшивания в оператор-сессии (первый промпт, свежий и стухший граф) — гейт фазы: не запускал, зона оператора. Механика покрыта тестами с fake-opencode.
