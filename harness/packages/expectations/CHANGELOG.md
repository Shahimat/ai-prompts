# Журнал @shahimat/expectations

Свежее сверху.

## 0.2.0

- `attention(...keys)` — принцип «внимание пользователя — самый дорогой
  ресурс»: вопрос только по необходимости, основная сессия — на доменной
  области.
- `ticketCommits(...keys)` — доказательства по якорям `expect:KEY`, а не
  по путям.
- Уточнено: «по умолчанию коммит делает пользователь» — не противоречит
  git-записи агента по явной просьбе.
